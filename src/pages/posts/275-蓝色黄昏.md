## 潮流工具

**Bento：把在线 PPT 塞到一个文件里**
<https://github.com/nyblnet/bento>
这个思路和解决方案不错，动画、视频、网页设计啥的都放进一个 HTML 里面，这个文件同时也是你的文档、编辑器和播放器，也很适合让 AI 持续编辑迭代，有兴趣的小伙伴可以去玩玩看。
<img src="https://cdn.tw93.fun/uPic/zHKfAj50.png" width="800" />

**peek-cli：让你的 Coding Agent 更好看到网页**
<https://github.com/puffinsoft/peek-cli>
peek-cli 可以让 Agent 直接截取浏览器里任意一个已打开标签页的画面，适合在反复迭代前端设计的场景里持续调到最好的效果。
<img src="https://cdn.tw93.fun/uPic/qa3wJh33.png" width="800" />

**clawk：给你的 Coding Agent 一个一次性的 Linux 虚拟机**
<https://github.com/clawkwork/clawk>
担心 AI Coding 的执行破坏你的电脑，或者你非常喜欢用 `--dangerously-skip-permissions`，又怕泄露密钥啥的，可以试试这个工具，它会自动帮你创建一个一次性的 Linux 虚拟机，防止运行过程中出事。
<img src="https://cdn.tw93.fun/uPic/demo47.gif" width="800" />

**好久没有给大伙同步 Kaku 的更新了**
<https://kaku.fun>
这个是我过年期间基于 WezTerm 深度魔改定制的一个 AI 友好、默认好看、性能很棒的开源 Mac 终端，当前累计迭代了 23 个版本，从最开始的很简单，到现在看着还是很简单，但是功能越用越顺手，也补充上了官网，加上了友好的使用文档。

我平时把他当做我的主要工作站，相比 GUI 我现在还是喜欢 TUI，因为简单干脆，所以我的开源产品以及 Mole 差不多 90% 的代码是通过 Kaku 终端来实现的。最近开始用云端服务器部署一些自己的东西，终于完善了一下 SSH 的使用，也借助 Fable 5 优化了不少 Rust 底层渲染的性能，启动速度快了很多。我比较习惯一个项目一个 Tab，Tab 里用快捷键分成两屏，一边 coding 一边测试一些东西，非常方便，切换和关闭 Tab 几乎和浏览器一样，不少原来你在浏览器里的顺手操作被我移植到了终端上面。

说到 AI，Kaku 属于不打扰那种，一般会出现在你执行命令错了，或者忘记了一个命令直接说 #人话 他会告诉你实际命令，或者是你不想打开 codex，可以直接 CMD+L 唤起一个 AI 聊天面板直接聊天，把终端当做你的一个天然 AI 友好的环境。最近 2 个版本主要修复了不少使用上的体验问题，包括 AI 的使用、标签的快捷关闭、Starship 的兼容、在 SSH 里面的使用，还有分屏导航、重命名标签等等细节的优化，假如你想简单快速，喜欢好看的东西，那就欢迎你试试这个开源的终端 Kaku，也很欢迎你提使用过程中的建议，帮助 Kaku 做得更好。

## 随便看看

**Andrej Karpathy 这个口喷式大段话给到 AI 不错**
<https://x.com/karpathy/status/2079610838143623371>
和 LLM 协作有一种很好用的方式：往椅背上一靠，切到语音输入，随口絮叨个十分钟，乱七八糟，想到哪说到哪，开头还可以先交代一句“我在用语音识别，有错别字请见谅”。不知道为什么，LLM 很擅长从这种又长又乱的絮叨里把内容重新整理出来，它复述回来的版本，往往比你自己讲的那一遍清楚得多，后面聊起来更顺，要纠正的地方也更少。
<img src="https://cdn.tw93.fun/uPic/mtf8tr09.png" width="800" />

**Dan Shipper 关于 Claude Opus 5 的这个评价我挺赞同**
<https://x.com/danshipper/status/2080700057892815114>
花了一周时间，在编码、写作、知识工作和自己的智能体上把 Opus 5 全面测了一遍，结论是这个模型很难让人喜欢，会跟你的指令对着干，活还没干完就停下来，和原来的技能、插件也配合不好。后来把旧技能全删了从头搭，效果反而好了很多，所以别硬塞进已有的工作流，思考级别调到中或者低也比开满好用。最难的活还是留给 Fable，其他都给 GPT-5.6，Opus 5 像“穷人版 Fable”，有天才模型的脾气却没有天才的上限，卡在一个挺尴尬的中间位置。
